# 🏦 Bank Simulation v3.0

A simple **banking simulation program built with Python**.
This project was originally created as a basic banking system and has now been updated to use **JSON for data storage instead of a ****`.txt`**** file**.

## ✨ Features

* 👤 Create a new bank account
* 🔐 User login with password
* 💰 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 📊 Store user account information
* 💾 Persistent data storage using JSON
* 🗂️ Separate user data stored in a structured format

## 🆕 Update

### JSON Data Storage

The project previously stored account information in a `.txt` file.

It has now been updated to use a **`.json`**** file**, making the stored data more structured and easier for the program to read and modify.

**Previous:**

```text
data.txt
```

**Now:**

```text
data.json
```

JSON makes the data easier to organize because information can be stored using keys and values.
